CMNT Squad Tracker Project

CMNT (Canada Men's National Team) Squad Tracker is a web app that tracks Canada Men's National Team players and their current club form leading up to this Summer's World Cup. It surfaces each player's most recent club appearance with key indicators like minutes, goals, assists, results, and a last-updated timestamp to keep the data meaningful ahead of international windows. The site is built with Next.js, TypeScript, and CSS Modules, and is hosted on S3 with CloudFront serving files to the browser at cmnt.marcushenry.ca.

Player data is kept fresh by an automated daily pipeline: an EventBridge Scheduler triggers an ECS Fargate task every day at 3:00 AM MT. The task pulls its container image from ECR, retrieves the API key from Secrets Manager, and fetches live fixture and stats data from the API-Football external API. It then writes updated players.json and contention.json files to the S3 bucket, with all runs logged to CloudWatch for monitoring. GitHub Actions handle site deployments to S3, excluding the data/* path so the pipeline-managed data is never overwritten. This project serves as a portfolio piece to demonstrate cloud architecture, containerised workloads, automated data pipelines, and modern CI/CD practices while delivering a useful, data-driven product.
